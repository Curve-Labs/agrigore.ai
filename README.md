# agrigore.ai

The public page for **Agrigore**, situated agricultural intelligence: advice for farmers built from research, local experts and growers, kept with the place where it holds. Its first incarnation is **Livia**, for the olive groves of the Northern Aegean.

- `index.html` is the whole site: one self-contained page (English and Turkish, light and dark, scroll and slides).
- GitHub Pages serves it at https://agrigore.ai. `CNAME` holds the domain.
- The Livia waitlist form posts to the Egregore API (`/api/waitlist/livia`).
- A review copy is published at https://egregore.xyz/view/curvelabs/agrigore.

Agrigore is built on [Egregore](https://egregore.xyz). Contact: agrigore@egregore.xyz
